# RealmForge Scene Studio

Standalone offline prototype, isolated from existing BTU and 9router modules.

Open `index.html` in a browser. Import an image, place a simulated cube or sphere, drag, adjust controls, and export PNG.

Verification: HTML parsed and embedded JavaScript passed `node --check` locally. Browser interaction, Android APK, AR tracking, real 3D and AI video inference remain unverified/unimplemented.
