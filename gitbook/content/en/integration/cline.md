# Cline Integration

Connect the Cline VS Code extension to 9Router.

---

## Configuration

1. In VS Code, open the **Cline** panel.
2. Click the **Settings** (gear) icon.
3. In **API Provider**, select **OpenAI Compatible**.
4. Set:
   - **Base URL**: `http://localhost:20128/v1`
   - **API Key**: `sk_9router`
   - **Model ID**: `cc/claude-opus-4-7` (or your combo name)
5. Save settings.
