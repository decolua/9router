# Roo Code Integration

Connect Roo Code (Roo Clinic / VS Code Extension) to 9Router.

---

## Configuration

1. Open the Roo Code settings in VS Code.
2. Select **OpenAI Compatible** as provider.
3. Configure the connection:
   - **Base URL**: `http://localhost:20128/v1`
   - **API Key**: `sk_9router`
   - **Model ID**: `cc/claude-opus-4-7` (or any combo name)
4. Save settings.
