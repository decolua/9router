# Quota Tracking & Analytics

Monitor your real-time token consumption, reset windows, and estimated cost savings in one centralized dashboard.

---

## What the Dashboard Tracks

- **5-Hour Rolling Windows**: Claude Code and OpenAI Codex quota status.
- **Reset Countdowns**: Exact hours/minutes remaining until daily or weekly quota resets.
- **Token Ingestion & Output**: Real-time breakdown of prompt vs completion tokens per request.
- **RTK Savings**: Statistics showing how many tokens were saved by RTK output compression.

---

## Understanding Dashboard "Costs"

> **Important:** 9Router is free software and never bills you.
>
> The cost figures displayed in the dashboard analytics are **reference calculations**. They show what the equivalent usage would cost on direct pay-as-you-go API pricing, illustrating how much you save by using subscriptions and free tiers.
