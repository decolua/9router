# Triage Labels

The canonical triage roles used in this repo. Since the tracker is local markdown, these are values for the `Status:` field in ticket files, not GitHub labels.

| Role | Value | Meaning |
| :--- | :--- | :--- |
| **Needs Triage** | `needs-triage` | Maintainer needs to evaluate. |
| **Needs Info** | `needs-info` | Waiting on reporter/user for more information. |
| **Ready for Agent** | `ready-for-agent` | Fully specified, ready for an AFK agent. |
| **Ready for Human** | `ready-for-human` | Needs human implementation (judgment/design). |
| **Won't Fix** | `wontfix` | Will not be actioned. |

## Categories
Tickets should also imply a category (bug vs enhancement) in their title or content, though no strict prefix is enforced in the local markdown format yet.
