`NODE_OPTIONS=--stack-trace-limit=50 NEXT_TELEMETRY_DISABLED=1` so a crash would
print a deep stack instead of Next's default ignore-listed truncation.

- Phase A: 1 cold build in the main tree (`rm -rf .next && npm run build`).

established from the available evidence. The durable mitigation is the CI build
leg (part 2): if the crash recurs at any HEAD, CI now fails and — because the
