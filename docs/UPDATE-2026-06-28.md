# UPDATE-2026-06-28: Auto Context Length Info

## Mục đích

Tự động thu thập và cập nhật `context_length` (max tokens) cho mọi model, để:
1. `/v1/models` endpoint trả về `context_length` chính xác cho Codex/OpenAI clients
2. Combo fallback không thử model nhỏ trước model lớn một cách mù quáng
3. Proactive truncation (tương lai) có thể sử dụng context info

## Nguồn dữ liệu (theo thứ tự ưu tiên)

| Nguồn | Ưu tiên | Chi phí | Ghi chú |
|-------|---------|---------|---------|
| Provider `/v1/models` API | 1 | 1 API call / 24h | Tự động, chính xác |
| Parse 400 error | 2 | 0 | Học từ lỗi thực tế |
| MODEL_INFO static | 3 | 0 | Fallback cuối cùng |

## Cơ chế hoạt động

### 1. Fetch provider API (nguồn 1)

Mỗi provider hỗ trợ `/v1/models` endpoint:
- **NVIDIA**: `GET https://integrate.api.nvidia.com/v1/models` — không cần auth
  - Response: `{ data: [{ id, max_model_len }] }`
- **Khác**: OpenAI-compatible `/v1/models` — cần API key

Cache 24h vào SQLite.

### 2. Parse lỗi 400 (nguồn 2)

Khi nhận HTTP 400 với message chứa:
```
"maximum context length is {NUMBER} tokens"
```
Parse số `NUMBER` → update cache ngay lập tức.

### 3. Static MODEL_INFO (nguồn 3)

Giữ nguyên `open-sse/config/models.js` làm fallback cuối cùng.
Thêm static info cho các model phổ biến:
- NVIDIA NIM: minimax-m2.7 (204800), minimax-m3 (1024000), v.v.
- MiniMax direct: minimax-m2.7, minimax-m3

## Cache schema (SQLite)

```sql
CREATE TABLE IF NOT EXISTS model_context_info (
  model_id      TEXT PRIMARY KEY,   -- e.g. "nvidia/minimaxai/minimax-m2.7"
  context_length INTEGER,            -- max tokens, e.g. 204800
  source        TEXT,                -- "api" | "error" | "static"
  updated_at    INTEGER              -- Unix timestamp ms
);
```

Thêm resolver cho provider có `/v1/models` endpoint:

### `open-sse/services/accountFallback.js`

Sau khi nhận lỗi 400 context:

```js
// Trong handleSingleModelAccount
import { updateContextLengthFromError } from "open-sse/diepxuan/contextLength/errorParser.js";

```
