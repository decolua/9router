# Phase specs

This directory is the designated home for per-phase federation specs.

The authoritative federation design document is
[`../federation-spec.md`](../federation-spec.md) — its §5 ("Phase breakdown")
carries the per-phase specifications for FED-001…FED-006 (scope, acceptance
criteria, and the spec cross-references each board task row points at).

As phases are extracted into standalone documents (or new phases are added),
they land here as `FED-NNN.md` and are linked from `../federation-spec.md`.
