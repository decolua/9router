# UPDATE 2026-05-11 — AliCode Usage: Ẩn Reset Countdown cho 5h & Weekly

## Vấn đề

AliCode có 3 windows: 5h, weekly, monthly.

- **5h** và **weekly** là counting real-time đến hiện tại (không phải fixed reset) → không nên hiển thị "Reset in" và "Reset at" vì gây hiểu nhầm.
- **Monthly** đếm trong tháng → cần giữ nguyên reset info.

## Thay đổi

### 1. `src/lib/db/repos/manualQuotaRepo.js`

- Thêm flag `hideReset` cho 5h và weekly windows.
- 5h + weekly: `resetAt = null`, `resetCountdown = null`, `hideReset = true`.
- Monthly: giữ nguyên `resetAt`, `resetCountdown`.

### 2. `src/app/(dashboard)/dashboard/usage/components/ProviderLimits/utils.js`

- Truyền `hideReset` từ raw quota data qua normalized quota object (case `alicode`, `alicode-intl`).

### 3. `src/app/(dashboard)/dashboard/usage/components/ProviderLimits/QuotaProgressBar.js`

- Nhận thêm prop `hideReset` (default `false`).
- Khi `hideReset = true`: set `countdown = null`, `resetDisplay = null` → ẩn "Reset in" và "Reset at".

### 4. `src/app/(dashboard)/dashboard/usage/components/ProviderLimits/ProviderLimitCard.js`

- Truyền `hideReset={quota.hideReset}` vào `<QuotaProgressBar />`.

## Kết quả hiển thị

| Window | Progress bar | Reset countdown | Reset time |
|--------|:---:|:---:|:---:|
| 5h requests | ✅ | ❌ | ❌ |

## Scope

- Chỉ ảnh hưởng UI cho AliCode/AliCode-Intl provider.
- Không ảnh hưởng providers khác.
- Không thay đổi counting logic.
